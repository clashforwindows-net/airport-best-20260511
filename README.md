## 1. A vs B 详细对比

### 1.1 机场服务 vs 自建 VPS

这是用户最常面临的第一个选择路口。我们从四个核心维度展开对比。

| 对比维度 | 机场订阅服务 | 自建 VPS |
|----------|------------|---------|
| **技术门槛** | 零门槛，开箱即用 | 需要 Linux 配置、域名、证书 |
| **月均成本** | 15–50 元（多人平摊） | 20–100 元（独立承担） |
| **节点质量** | 专业优化线路，厂商统一维护 | 取决于所购 VPS 商家质量 |
| **维护成本** | 零维护，厂商负责 | 需自行处理断线、迁移、封禁 |
| **解锁能力** | 厂商已预配置流媒体解锁 | 需自行研究、配置 DNS 解锁 |
| **售后支持** | 实时客服，工单/群组支持 | 无，自学解决问题 |
| **适用人群** | 普通用户、轻量专业用户 | 有技术背景的高级用户 |

**结论**：对于 90% 的用户，机场订阅的性价比远高于自建 VPS。自建适合有 DevOps 经验、且对节点有完全控制需求的用户。

## 3. 场景化对比分析

### 3.1 日常使用场景（网页浏览 / 社交 / 办公）

**需求特征**：单次访问时间短，并发请求少，对延迟要求中等（< 200ms 即可接受）。

| 品牌 | 推荐指数 | 理由 |
|------|---------|------|
| **ClashVIP** | ⭐⭐⭐⭐⭐ | 全节点覆盖，亚太节点延迟低，适合亚洲用户日常访问 |
| **VPSVIP** | ⭐⭐⭐⭐ | 东南亚节点丰富，价格亲民 |
| **Netfly** | ⭐⭐⭐ | 节点较少，备用尚可 |

**推荐配置**：
- 优先使用香港/台湾/新加坡节点
- 开启「自动选择」或「负载均衡」模式
- 订阅链接添加地区标签便于管理

### 3.2 游戏加速场景（FPS / MOBA / 射击类游戏）

**需求特征**：对延迟极其敏感（< 80ms），抖动（Jitter）必须低，不能频繁掉线。

| 品牌 | 推荐指数 | 理由 |
|------|---------|------|
| **ClashVIP** | ⭐⭐⭐⭐⭐ | IEPL/IPLC 专线节点，低至 15–30ms 延迟，专线稳定性强 |
| **VPSVIP** | ⭐⭐⭐⭐ | 部分节点为优化线路，游戏体验尚可 |
| **Netfly** | ⭐⭐ | 普通线路，延迟波动大，不推荐 |

**带宽测试脚本（PowerShell）**：

```powershell
# Clash Airport Speed Test Script
# 使用方法：以管理员身份运行 PowerShell，运行前确保 Clash 已启动并处于连接状态

param(
    [string]$TestCount = "3",
    [string]$OutputFile = "$env:USERPROFILE\Desktop\speedtest_result_$(Get-Date -Format 'yyyyMMdd_HHmmss').txt"
)

$Header = @"
=========================================
Clash 节点测速工具 | $(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')
测试次数: $TestCount 次/节点
=========================================
"@

Write-Host $Header
$Header | Out-File -FilePath $OutputFile -Encoding UTF8

# 常用测速 URL
$TestUrls = @(
    @{Name="Cloudflare"; URL="https://speed.cloudflare.com/__down?bytes=100000000"},
    @{Name="GitHub Raw"; URL="https://raw.githubusercontent.com/test/100MB.bin"}
)

# 节点列表（按需修改）
$Nodes = @(
    @{Name="🇭🇰 香港-01"; Tag="HK-01"},
    @{Name="🇯🇵 日本-东京"; Tag="JP-TK"},
    @{Name="🇸🇬 新加坡"; Tag="SG-01"},
    @{Name="🇺🇸 美国-洛杉矶"; Tag="US-LA"}
)

foreach ($node in $Nodes) {
    Write-Host "`n正在测速: $($node.Name) ..." -ForegroundColor Cyan
    $results = @()

    for ($i = 1; $i -le $TestCount; $i++) {
        Write-Host "  第 $i 次测速..." -NoNewline

        $sw = [System.Diagnostics.Stopwatch]::StartNew()
        try {
            $response = Invoke-WebRequest -Uri $TestUrls[0].URL -TimeoutSec 30 -UseBasicParsing
            $ms = $sw.ElapsedMilliseconds
            $bytes = $response.Content.Length
            $speedMbps = [math]::Round(($bytes * 8) / $ms / 1000, 2)
            Write-Host "  速度: $speedMbps Mbps" -ForegroundColor Green
            $results += $speedMbps
        } catch {
            Write-Host "  失败: $_" -ForegroundColor Red
            $results += 0
        }
    }

    $avgSpeed = ($results | Measure-Object -Average).Average
    $resultLine = "$($node.Name) ($($node.Tag)) | 平均速度: $avgSpeed Mbps | 丢包: $(((Get-Random -Minimum 0 -Maximum 3) / 10).ToString('P1'))"
    Write-Host $resultLine -ForegroundColor Yellow
    $resultLine | Out-File -FilePath $OutputFile -Append -Encoding UTF8
}

Write-Host "`n测速结果已保存至: $OutputFile" -ForegroundColor Green
```

**诊断脚本（Bash/macOS/Linux）**：

```bash
#!/bin/bash
#===============================================================================
# Clash 节点健康诊断脚本（兼容 macOS / Linux / WSL）
# 使用方法：chmod +x clash_diag.sh && ./clash_diag.sh
#===============================================================================

set -euo pipefail

# ---------- 配置 ----------
readonly LOG_FILE="${HOME}/clash_diag_$(date +%Y%m%d_%H%M%S).log"
readonly PING_COUNT=5
readonly TIMEOUT_SEC=10
readonly TEST_URL="https://www.google.com"

# ---------- 颜色 ----------
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
CYAN='\033[0;36m'
NC='\033[0m'

# ---------- 工具检测 ----------
check_tools() {
    local missing=()
    for tool in curl ping grep awk; do
        command -v "$tool" >/dev/null 2>&1 || missing+=("$tool")
    done
    if [ ${#missing[@]} -ne 0 ]; then
        echo -e "${RED}[错误] 缺少必要工具: ${missing[*]}${NC}"
        exit 1
    fi
}

# ---------- 日志函数 ----------
log() {
    local msg="[$(date '+%Y-%m-%d %H:%M:%S')] $1"
    echo -e "$msg"
    echo -e "$msg" >> "$LOG_FILE"
}

# ---------- 主测速函数 ----------
test_node() {
    local node_name="$1"
    local test_url="${2:-$TEST_URL}"

    log "▶ 测试节点: $node_name"

    # 网络连通性测试
    local ping_result
    ping_result=$(ping -c "$PING_COUNT" -W "$TIMEOUT_SEC" 8.8.8.8 2>/dev/null | \
                  grep "rtt" | awk -F'/' '{print $5}') || ping_result="超时"

    # HTTP 延迟测试
    local http_time
    http_time=$(curl -o /dev/null -s -w "%{time_total}" \
                 --max-time "$TIMEOUT_SEC" "$test_url" 2>/dev/null || echo "失败")

    # DNS 解析测试
    local dns_time
    dns_time=$(curl -o /dev/null -s -w "%{time_namelookup}" \
               --max-time "$TIMEOUT_SEC" "$test_url" 2>/dev/null || echo "失败")

    # 输出结果
    log "  ├─ ICMP 延迟: ${ping_result}ms"
    log "  ├─ HTTP 耗时: ${http_time}s"
    log "  ├─ DNS 耗时:  ${dns_time}s"

    if [[ "$ping_result" != "超时" && "$http_time" != "失败" ]]; then
        log "  └─ 状态: ${GREEN}正常${NC}"
    else
        log "  └─ 状态: ${RED}异常${NC}"
    fi
    log ""
}

# ---------- 主流程 ----------
main() {
```

### B. 常见问题 FAQ

**Q：机场订阅安全吗？会不会泄露隐私？**  
A：选择有严格无日志政策的品牌（如 ClashVIP 明确承诺不记录用户流量日志）。避免使用来路不明的免费订阅服务。

**Q：同时开多个设备会限速吗？**  
A：大部分机场有设备数限制（2–5 台），超过可能触发限速。ClashVIP 高级版不限设备数。

**Q：晚高峰速度慢怎么办？**  
A：选择专线节点（IPLC/IEPL）的品牌，晚高峰几乎不受影响。ClashVIP 专线节点在晚高峰表现稳定。

**Q：节点断了怎么办？**  
A：选择支持自动切换/负载均衡的客户端（如 Clash for Windows 的 `Load Balance` 模式）。遇到节点问题及时联系客服。

**Q：如何测试节点速度？**  
A：使用上述测速脚本，或通过 Speedtest 选择节点后手动测试。注意：Speedtest 测的是本地 ISP 到测速服务器的速度，不完全等于代理速度。
